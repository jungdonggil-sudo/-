# 롯데몰 동부산점 식당가 식품위생 건강 관리 플랫폼 프로토타입

본 플랫폼은 식당가 임직원들이 자신의 휴대폰을 사용하여 보건증을 업로드하면, AI OCR 기술을 시뮬레이션하여 보건증에서 필수 정보를 실시간으로 추출하고 관리자가 PC와 모바일에서 효율적으로 모니터링할 수 있는 반응형 단일 페이지 애플리케이션(SPA) 프로토타입입니다.

---

## 1. 프로젝트 폴더 구조 및 확장 아키텍처

현재 프로토타입은 초보자가 별도의 복잡한 백엔드 서버나 DB 설치 없이 웹 브라우저에서 더블 클릭하는 것만으로 실행할 수 있도록 단일 파일(`index.html`)로 통합 구축되었습니다. 

향후 **"식당가 통합 운영 AI 플랫폼"**으로 고도화 및 제품화 시에는 아래와 같이 모듈별로 디렉토리를 분리하여 개발 및 확장할 수 있도록 설계 구조를 표준화하였습니다.

```plain
health-cert-platform/
│
├── index.html          # 종합 프론트엔드 UI 및 가상 클라이언트 로직 (SPA)
├── README.md           # 본 안내 문서 (실행방법, 예외처리 및 확장 가이드)
│
├── css/
│   └── custom.css      # 브랜드(롯데 레드 테마) 커스텀 스타일시트
│
├── js/
│   ├── app.js          # 모바일/PC 라우팅 및 뷰(View) 렌더링 엔진
│   ├── ocr-service.js  # Naver CLOVA OCR 또는 Google Cloud Vision API 연동 모듈
│   ├── store.js        # REST API / IndexedDB 연동을 통한 직원 위생 상태 데이터 영구 스토어
│   └── chart-config.js # Chart.js 기반 통계 차트 설정 모듈
│
└── assets/
    └── images/         # 보건증 업로드 원본 이미지 임시 보관소
```

## 2. 핵심 구현 기능 및 개인정보 보호 조치

1. **역할별 뷰(View) 분기**:
   - **직원용**: 별도 로그인 없이 직관적인 큰 버튼으로 브랜드를 선택하고, 직책 및 성별 선택 후 사진/파일을 업로드하는 모바일 퍼스트 단계식 양식.
   - **관리자용**: 기본 비밀번호(`2606`)를 통해 안전하게 관리자 전용 대시보드 화면에 접속 가능하며, 대시보드 내 **비밀번호 변경 기능**을 제공하여 지속적인 계정 관리를 지원합니다.
2. **AI OCR 및 만료일 계산 시뮬레이션**:
   - 파일 업로드 시 **AI OCR 데이터 추출 로딩 애니메이션**이 구동되며, 가상으로 이름, 주민번호, 진단일자, 판정결과가 99.8% 정확도로 자동 기입됩니다.
   - 진단일자를 기준으로 **1년 후의 하루 전(유효기간 만료일)**을 자동 연산하여 화면에 제공하고, 현재 시간 대비 **D-Day를 실시간 계산**하여 등급별 뱃지를 활성화합니다.
3. **엄격한 개인정보보호 구현**:
   - 개인정보보호법에 의거하여 **주민등록번호 뒷자리는 웹 스토리지(LocalStorage)에 절대 저장하지 않습니다**.
   - OCR 시뮬레이션 결과 및 원본 증명서 열람 시 항상 **`980412-1******`** 형태로 첫 성별 구분자를 제외한 뒷자리는 아스테리스크(`*`) 마스킹 처리되어 보관됩니다.
4. **시각적 대시보드 및 통계 (Chart.js)**:
   - 총 근무자 수, 최근 한 달 등록 건수, 7일 임박 건수, 30일 임박 건수, 기한 만료 건수가 카드 형태로 상단에 실시간 동기화됩니다.
   - **브랜드별 보건증 현황(Doughnut)**, **만료 임박 및 기한 상태 분포(Bar)**, **월별 보건증 등록 추이(Line)** 차트가 실시간 필터 및 검색 결과에 맞춰 동적으로 업데이트됩니다.
5. **백업 및 정렬/검색**:
   - 브랜드별 추가 및 실시간 삭제(동작 연동형)가 가능합니다.
   - 브랜드 검색, 임직원 이름 검색, 정상/임박/만료 등 다차원 실시간 필터링을 지원합니다.
   - **SheetJS(xlsx.js)** 라이브러리를 연동하여, 필터링 및 누적된 위생 대장을 버튼 클릭 한 번으로 **Excel 문서로 즉시 다운로드**할 수 있습니다.

## 3. 로컬 실행 방법

1. 사용 중인 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 웹 브라우저를 엽니다.
2. `index.html` 파일을 마우스로 드래그 앤 드롭하거나 더블 클릭하여 실행합니다.
3. 별도의 웹 서버 구동 없이도 로컬 파일 환경(`file:///...`)에서 모든 스크립트 및 라이브러리가 CDN을 통해 즉시 동작합니다.
4. 새로고침하더라도 데이터가 소실되지 않도록 브라우저 내부의 `LocalStorage`에 실시간으로 데이터가 보존됩니다.

## 5. 예상 발생 오류 및 트러블슈팅

1. **현상: 로컬스토리지 권한 오류 (보안 프로그램 등으로 인한 차단)**
   - **이유**: 브라우저의 시크릿 모드 또는 강한 보안 정책으로 인해 `localStorage`에 데이터 접근 권한이 차단될 수 있습니다.
   - **해결**: 일반 크롬 창에서 실행하거나, 로컬 가상 서버(예: VS Code Live Server 등) 환경에서 동작시키면 정상 작동합니다.
2. **현상: 오프라인 환경에서 폰트, 아이콘 또는 차트가 표시되지 않음**
   - **이유**: Tailwind CSS, Lucide Icons, Chart.js, SheetJS 라이브러리는 CDN(온라인 주소)을 통해 외부망에서 실시간으로 가져옵니다.
   - **해결**: 반드시 인터넷이 연결된 환경에서 열어주십시오. 실제 서비스 고도화 단계에서는 해당 라이브러리 파일들을 프로젝트 내부 폴더에 로컬 저장하여 패키징합니다.
3. **현상: OCR 사진 업로드 시 PDF 또는 대용량 이미지의 시각적 렌더링 지연**
   - **이유**: 파일의 메타데이터 크기가 거대할 때 모바일 브라우저의 메모리 자원 부족으로 일시 지연될 수 있습니다.
   - **해결**: 실제 연동 시에는 업로드 전 프론트엔드 단에서 canvas를 통해 이미지 1차 압축(Resizing) 후 API로 전송하는 예외 처리를 권장합니다.
